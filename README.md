# Stop-scrolling-Android
打开娱乐 App 前，先停 5 秒，写明意图和时长，到点复盘。让刷手机这件事，回到你自己手里。

「别刷了！」是一款 Android 端的轻量级防沉迷工具。在你点开 B 站、小红书、抖音、知乎、微博的那一瞬间，弹出一个安静的拦截页 —— 让你花 5 秒钟，想清楚「我打开它是为了什么」「打算刷多久」。然后放你进去。倒计时开始。时间到了，复盘。

## 安装

### 直接下载 APK（推荐普通用户）

前往 [Releases](../../releases) 下载最新版 APK，传到安卓手机点击安装即可。

- 系统要求：**Android 8.0 及以上**
- 不支持 iPhone
- 安装时系统可能提示"未知来源"，按引导允许即可

## 首次使用

App 首次启动后，需要授予以下权限（App 内有引导）：

1. **悬浮窗权限** —— 显示倒计时悬浮球
2. **使用情况访问权限** —— 检测前台 App 切换
3. **后台自启动** —— 厂商机型需手动放行（vivo / 小米 / 华为 / OPPO 等）

然后在「设置 → 拦截的 App」中选择要拦截的应用即可。

预设 5 大主流 App（B 站 / 小红书 / 抖音 / 知乎 / 微博）支持带词直达搜索页；其他已安装 App 也可加入拦截列表，仅弹拦截页不跳搜索。
